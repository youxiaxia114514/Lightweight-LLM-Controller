# Lightweight-LLM-Controller
中文：极轻量级本地 LLM 图形控制台。基于原生 PowerShell + WinForms 构建，零 Node/Python 依赖，解压即用。支持免重启动态调整思考等级（Reasoning Effort）、自定义引擎路径与多模型隔离。 English: An ultra-lightweight local LLM GUI wrapper for llama.cpp built with native PowerShell + WinForms. Zero dependencies, portable out-of-the-box. Features hot-swappable reasoning effort and custom engine paths.
